# Kata: Object Calisthenics

Código de cálculo do total de um pedido escrito **de propósito** com os problemas mais comuns:
aninhamento profundo, `else`, tipos primitivos, abreviações e cadeias de acesso.

No módulo 04 do curso, ele é refatorado uma regra por aula. Os testes de caracterização
(`*.spec.ts`) protegem o comportamento durante todo o processo.

| Regra                                    | Aula  |
| ---------------------------------------- | ----- |
| 1. Um nível de indentação por método     | 04-03 |
| 2. Não use `else`                        | 04-03 |
| 3. Encapsule tipos primitivos            | 04-04 |
| 4. Coleções de primeira classe           | 04-05 |
| 5. Um ponto por linha                    | 04-06 |
| 6. Não abrevie                           | 04-07 |
| 7. Mantenha as entidades pequenas        | 04-07 |
| 8. No máximo duas variáveis de instância | 04-08 |
| 9. Sem getters e setters                 | 04-09 |

Este código não faz parte da aplicação: fica fora de `src/` e não entra no build.
